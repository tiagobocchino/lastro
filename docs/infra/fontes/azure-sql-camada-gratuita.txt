Azure SQL Database

Build and test relational and AI-powered applications with Azure SQL Database, a fully managed database that shares a common SQL Database Engine code base with SQL Server. Use familiar T-SQL and developer tools to build an application backend, combine relational and JSON data, or explore vector similarity search alongside application data. Azure manages engine patching and backups, so you can focus on your application rather than maintaining a database server.

The free tier provides recurring monthly allowances for new development and proof-of-concept databases. For each database, you get 100,000 vCore seconds, 32 GB of data, and 32 GB of backup storage free per month for the lifetime of your subscription. Each Azure subscription allows you to create up to 10 free tier General Purpose databases.

 Important

Start with a new development or sample database. You can't restore or convert an existing database to the free tier. The free tier has no service-level agreement (SLA), and feature and configuration restrictions apply. Choose whether to pause at the monthly free limit or allow paid overages. External AI models, application hosting, and other supporting resources can have separate charges. Review eligibility and limitations before creating resources.

 Tip

To get started and quickly create a new free Azure SQL Database, visit the Azure SQL hub at aka.ms/azuresqlhub. In the Create a database pane, select the Start free link.

What you can build

Use your SQL skills to explore these development projects:

A SQL application backend: Model related data in tables, query it with T-SQL, and use stored procedures for database logic. Review the feature comparison for supported database capabilities and differences from SQL Server instance features.
A relational and JSON project: Combine relational records with JSON documents, such as a product catalog with flexible attributes. Learn about JSON support.
A vector similarity prototype: Store prepared embeddings alongside sample application data and explore retrieval by similarity, such as finding related product descriptions. Start with the conceptual AI overview and vector search overview. These are learning resources, not a validated free tier AI sample. Check the chosen feature's prerequisites and free tier restrictions; model hosting and inference aren't included in this database offer.
Prerequisites

You need an Azure account and subscription. Unlike the previous Azure free account offer, the free tier is available with most Azure subscription types. Microsoft Azure for Students Starter isn't supported.

Before you create resources, confirm the tenant, subscription, region, resource group, and logical server you intend to use. Check that you have permission to create the required resources and configure connectivity. Review authentication, firewall changes, supporting resources, and potential charges before approving creation, whether you use a tool directly or ask an agent to help.

To create a free tier database in the Azure portal:

Go to Azure SQL hub at aka.ms/azuresqlhub.

In the pane Create a database, select Start free.

On the Basics tab:

Under Project details:
Select your Subscription. Your current subscription is already selected.
An existing Resource Group is already selected. You can select a different resource group or create a new one.
Under Database details:
Use the automatically created unique Database name, or provide a new name.
An existing logical Server is already selected. You can select a different logical server or create a new one.

The Cost summary card on the right side of the page shows an Estimated Cost/Month of zero. The database is created with default settings, including the option to pause the database when the free limits are reached. You can change these database settings later.

Optionally, to practice SQL with sample data, open Additional settings and set Use existing data to Sample before creating the database. For the sample-specific steps and exercises, see Learn SQL with AdventureWorksLT.

Select Review + create.

Review and select Create.

Verify the deployment

After creation finishes, confirm that:

The database is online in the intended subscription, resource group, and logical server.
The database uses the free tier. In Azure CLI output, useFreeLimit is true.
The behavior at the monthly free limit matches your choice. The creation examples in this article use AutoPause; BillOverUsage enables paid overages.

Use the database's Overview and Compute + storage pages in the Azure portal, az sql db show, or Get-AzSqlDatabase to check the configuration.

Query the database

After you create and verify the database, choose a tool or language from Connect and query Azure SQL Database. Confirm the query editor's target database before running statements.

 Important

A tutorial's generic CREATE DATABASE statement doesn't provision a free tier database. Keep using the database you created through the free tier offer. Choose sample table instructions that don't require another database, a restore, or an import.

In the MSSQL first-query quickstart, start with Use an existing database to use sample tables in your provisioned database without creating another database.

If you selected Sample during creation, continue with Learn SQL with AdventureWorksLT. The tutorial covers read-only queries, joins, and summaries, and includes a prompt for building a product explorer with an AI coding assistant.

Monitor and track service usage
Track free usage

Use the Azure portal to track the free amount remaining or consumed:

On the database Overview tab, you see a Free monthly vCore amount entry.

Select the seconds remaining amount. The Metrics chart launches where you can look at Free amount remaining or Free amount consumed metrics.

On the Metrics tab, you can also create an alert rule at no cost. Use the Free amount remaining metric to send an alert when the amount is less than 10,000 vCore seconds (10% of the monthly limit), so you know when you're running out for the month.

Monitor with Database Hub (preview)

Optionally, use Database Hub in Microsoft Fabric (preview) for an estate-wide view of Azure SQL databases that you have permission to access. It's available with a Fabric Free license and doesn't require Fabric capacity. Your databases remain in their existing Azure subscriptions.

For setup and preview prerequisites, see Monitor a Microsoft SQL database. To add performance data, see Enable performance monitoring for Microsoft SQL.

Upgrade to Hyperscale

As your workload grows, follow Upgrade a free tier database to Hyperscale for prerequisites, steps, and verification.

Allowing paid overages doesn't disable the free tier. Leaving it is permanent, and paid General Purpose usage can accrue even if Hyperscale conversion fails.

Considerations and limitations

The following considerations and limitations apply to Azure SQL Database free tier databases:

The free tier uses the same fully managed General Purpose infrastructure as a paid database, but it doesn't include a service-level agreement (SLA). Use it primarily for development and proof-of-concept scenarios.
Choose the behavior for when you reach the monthly free limit:
Auto-pause the database until next month stops charges, but the database is inaccessible until the allowance resets at the start of the next calendar month.
Continue using database for additional charges keeps the database online and bills overages at standard General Purpose serverless rates. You can't switch back to the auto-pause option.
The free tier databases automatically pause after 15 minutes of inactivity. The auto-pause delay is fixed and can't be changed, regardless of the selected behavior when the monthly free limit is reached.
Disconnect querying tools such as SQL Server Management Studio and the MSSQL extension for Visual Studio Code, including query editors and Object Explorer connections, when you're done. Open connections can prevent idle auto-pause and continue to consume vCore seconds. Disconnecting doesn't restore usage already consumed. If the database doesn't auto-pause, review features that prevent auto-pause.
You can apply the free tier only to a new database. You can't restore or convert an existing database to the free tier.
If you use Advanced configuration, the region selected for the first free tier database applies to all free tier databases in that subscription and can't be changed.

For backup, scaling, copying, and feature compatibility details, see the Azure SQL Database free tier FAQ.
